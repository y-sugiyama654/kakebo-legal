kakebo プライバシーポリシー

kakebo運営事務局(以下「運営者」といいます)は、共有型家計簿アプリ「kakebo」(以下「本サービス」といいます)で取り扱う利用者の情報の扱いを、以下のとおり定めます。

1. 収集する情報

本サービスは、次の情報を収集します。

  1. アカウント情報: GoogleまたはAppleのログインを通じて取得する識別子(FirebaseのユーザーID)、メールアドレス(Appleの「メールを非公開」の代替アドレスを含む)、氏名・表示名
  2. グループ情報: グループ名、グループコード、グループ内でのメンバー名
  3. 家計データ: 利用者が入力する支出の金額、支払日、支払先、メモ、カテゴリ、支払方法
  4. 問い合わせ内容: 問い合わせ時に連絡いただいた情報

クレジットカード番号や銀行口座番号は収集しません。銀行口座やカードとの連携もしていません。

2. 利用目的

収集した情報は、次の目的に限って利用します。

  • 本サービスの提供・運営(ログイン、グループでの家計データの共有、集計とグラフ表示)
  • ユーザーサポートと問い合わせへの対応
  • 不正利用の防止とセキュリティの確保
  • 本サービスの改善、新機能の検討(統計的に処理し、個人を特定しない形で利用します)
  • 重要なお知らせの連絡

広告の配信や、家計データを販売・マーケティング目的に利用することはありません。

3. グループ内での共有

本サービスは、同じグループに参加しているメンバー同士で家計データを共有することを目的としています。グループに登録された支出・メンバー名・カテゴリなどは、そのグループの全メンバーに表示されます。グループコードは参加する相手にだけ伝えてください。コードを知った第三者がグループに参加すると、データを閲覧できるおそれがあります。

4. 第三者への提供

運営者は、次の場合を除き、利用者の同意なく個人情報を第三者に提供しません。

  • 法令に基づく場合
  • 人の生命、身体または財産の保護に必要で、本人の同意を得ることが困難な場合

5. 委託先・外部サービス

本サービスは、運営のために次の外部サービスを利用しています。これらのサービスによって、情報が日本国外のサーバーで処理・保存される場合があります。

サービス提供者用途
Firebase Authentication / GoogleログインGoogle LLCログインの認証
Sign in with AppleApple Inc.ログインの認証
Amazon Web ServicesAmazon Web Services, Inc.APIサーバーとデータベースの運用、認証情報の管理
Apple App Store / TestFlightApple Inc.アプリの配信
GitHub PagesGitHub, Inc.利用規約・プライバシーポリシーなどのサイトの配信

6. 安全管理

運営者は、収集した情報を漏えい・滅失・毀損させないよう、通信の暗号化(HTTPS)、アクセス制限、認証情報の安全な管理など、合理的な安全管理措置を講じます。ただし、いかなるシステムも完全な安全性を保証するものではありません。

7. 保存期間とデータの削除

利用者の情報は、アカウントを利用している間保存します。利用者は、アプリ内の設定画面からいつでもアカウントを削除できます。削除を実行すると、メールアドレスやユーザーIDなどのアカウント情報を削除します。グループに登録した支出データの扱い: 他のメンバーが残っているグループでは、支出データは残し、あなたのメンバー名を「退会したメンバー」に置き換えます(あなたのアカウントとの紐づけは削除されます)。あなたが最後のメンバーだったグループは、支出・カテゴリ・支払方法などグループのすべてのデータを削除します。バックアップに残るデータは、最大14日以内に消去されます。

8. 開示・訂正・削除の請求

利用者は、ご自身の情報について、開示・訂正・削除・利用停止を請求できます。下記の問い合わせ先にご連絡ください。ご本人であることを確認したうえで、合理的な期間内に対応します。

9. 未成年者の利用

未成年者が利用する場合は、保護者の同意を得たうえでご利用ください。

10. 本ポリシーの改定

必要に応じて本ポリシーを改定します。重要な変更は、アプリ内またはサイトでお知らせします。改定後に本サービスを利用した場合、改定後のポリシーに同意したものとみなします。

11. 問い合わせ

本ポリシーに関する問い合わせは、kakebo.cs@gmail.comへお願いします。
